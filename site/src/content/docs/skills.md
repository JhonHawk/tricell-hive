Hive's skills supply procedures when a task needs them. The agent selects the
relevant skill; you can also name one in your request. The linked source files
hold the canonical rules.

## Main flows

- [Research](/flows/research/): investigate an uncertain question and report evidence.
- [Plan](/flows/plan/): settle consequential decisions and define verifiable work.
- [Build](/flows/build/): implement authorized changes and hand over a built candidate.
- [Verify](/flows/verify/): check the candidate at the level you set, then integrate it.
- [Security](/flows/security/): review a change's security boundaries when you ask.
- [Close](/flows/close/): record the outcome and clean up the work session.
- [Deploy](/flows/deploy/): promote an integrated change and check what is served.

## Supporting skills

- [Git workflow](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/git-workflow/SKILL.md): prepare authorized Git delivery while preserving unrelated work.
- [Visual reports](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/flow-report/SKILL.md): present a report, comparison, or explainer as a designed page.
- [Starlight documentation sites](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/starlight-docs-site/SKILL.md): scaffold, extend, or audit maintained documentation sites.
- [Harness audit](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/harness-audit/SKILL.md): audit agent instructions, skills, and role definitions, ask the decisions the findings need, and apply what you accept in the current project, including creating or updating a repository's `## Hive` section.
- [Security advisories](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/security-advisory/SKILL.md): check whether a published advisory affects your repositories, without changing them.
- [Flow walkthrough](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/flow-walkthrough/SKILL.md): walk a built screen for you to validate, with captures and the viewer page.
- [Workspace conventions](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/workspace-conventions/SKILL.md): organize support material and retain useful evidence.
- [Workspace archive](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/workspace-archive/SKILL.md): archive explicitly selected, closed support sessions.
- [Unattended delegation](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/unattended-delegation/SKILL.md): keep bounded work going after you delegate it, say you are leaving, or go quiet once you have answered the route question and each delivery and review value is answered.
- [Engram workspace initialization](https://github.com/JhonHawk/tricell-hive/blob/master/content/skills/engram-init-workspace/SKILL.md): establish an explicit workspace memory identity when requested.
