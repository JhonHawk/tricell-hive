# Linear

Read from [trackers](../trackers.md) for a ticket whose key the `## Hive` assigns to Linear. Act in the order [trackers](../trackers.md) sets: the Linear CLI, then the host's Linear MCP tools, then its GraphQL API. Read the tool's current description before the first use in a session.

- A state belongs to its team: take the exact name to move to from that team's states list (each with its `type`), which is also the transition read of [trackers](../trackers.md) step 2, since Linear lets an issue move to any state of its team.
- To attach, upload the file through the tool's upload step and then attach it, or embed the uploaded file in the comment as the upload step returns it.
- Categories: a state's `type` is `backlog` or `unstarted` for to do, `started` for in progress, `completed` for done, and `canceled` for other.

Time: [time](time.md) sets it.
