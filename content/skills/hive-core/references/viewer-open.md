# Open the viewer

Read at a stop where the user reviews captures. It applies at each such stop, such as a UI walkthrough or a build's first rendered view.

Never open the viewer on your own, and never ask about it on its own. At each stop where the user reviews captures, a UI walkthrough including a build's first rendered view, offer it inside what that stop already asks:

- **In the card.** Add one option, `<letter> - Open the viewer`, to the stop's own acceptance or validation question, as that decision's last option in the card and, where [asking in text](questions.md) writes the round in the text, as its last option line: never first, never with `(★)`, without an `If you choose it:` line and without a decision ID of its own. When the question already holds the most options the tool accepts, use the reply line below.
- **When the user picks it.** Run `hive view open` once for the work (`--session-id ID` when several sessions are open), then ask the same question again through the question tool, with the same ID, title, situation and options except this one, keeping the round's other answers; the message before it is one line, such as "The viewer is open; D7 again". This changes four rules of [decision format](questions.md) and [asking a round](questions.md): an ID is never reused, the text before a round's first card holds the context line, the report and the waiting line, nothing follows the round's last card but the reply to an unanswered card, and every option carries an `If you choose it:` line. Ask the round's remaining cards first, unless one comes back unanswered, then open the viewer and ask the question again.
- **Without a card, or when the round was already asked.** Add *open the viewer* as one more reply: in the waiting line, or as a lettered reply of the next-step block; when the user uses it, run `hive view open` once while the stop keeps waiting.
- **After that.** Once the user opened it, do not offer or reopen it in this conversation unless asked; when the user answers without opening it, offer it again at the next such stop.
