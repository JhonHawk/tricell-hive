# Verify current state

Read before you present as current something you recalled or summarized, and before you answer about how a library, framework, SDK, API, CLI tool or cloud service behaves.

1. Recalled memory and prior summaries are claims about past state. Verify the current state before presenting it, or say it is unverified.
2. For a library, framework, SDK, API, CLI tool or cloud service, read its current documentation through Context7 when it is installed, rather than relying on memory. Without Context7, read the official documentation.
