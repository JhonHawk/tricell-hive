# Review evidence

Read before treating a code finding as confirmed. Read it in the code review and when the main thread adjudicates findings.

It applies to the code reviewer and to the main thread, native review output included. Read the affected code and cited sources against the current candidate. When the behavior can be reproduced locally within authorized effects and without changing another task's work, run a focused reproduction and report its command, expected result and actual output. For a contradiction in instructions, a contract or a project rule that reading establishes, cite the conflicting sources. When a reproduction is unavailable or needs an unauthorized effect, state that limit and distinguish conclusive source evidence from a plausible concern. A reviewer's assertion alone does not confirm a finding. Say whether the failing input existed before the review or the reviewer built it: for pattern-matching code, that decides the finding's highest priority, as [close report](../close/close-report.md#findings) «Findings» sets.
