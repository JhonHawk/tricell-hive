# Review evidence

Read before treating a code finding as confirmed. Read it in the code review and when the main thread adjudicates findings.

It applies to the code reviewer and to the main thread adjudicating findings, including output from a native review. Read the affected code and cited sources against the current candidate before treating a finding as confirmed. When a suspected behavior can be reproduced locally with the available tools and environment, within authorized effects and without changing another task's work, run a focused reproduction and report its command, expected result and actual output. For a contradiction in instructions, a contract or a project rule that reading establishes, cite the conflicting sources. When a reproduction is unavailable or would need an unauthorized effect, state that limit and distinguish conclusive source evidence from a plausible concern. A reviewer's assertion alone does not confirm a finding.
