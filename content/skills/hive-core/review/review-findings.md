# Review findings and the round of fixes

Read when a verify's reviews and the user's answer are in. Read it before fixing anything: how to judge a finding and how to run the one round of fixes.

- **Confirm first.** Apply [Review evidence](review-evidence.md) before accepting a code finding. Report instead of fixing each finding the reviewer marked plausible rather than confirmed, or whose evidence you cannot confirm.
- **One round of fixes** for the user's corrections, every UI defect the change introduced and each confirmed blocking finding (P1 or higher on the scale of [close report](../close/close-report.md#findings)); recommend approving no known defect as is. Fix only what each finding names, except that a defect is fixed as [defect fix](../build/defect-fix.md) sets, at its cause and with its other instances. Recheck and recapture as [UI verification](../ui/ui-verification.md) sets, and reread a correction of the UX reviewer's finding as [reviewer brief](../delegation/reviewer-brief.md) sets.
- **A UI defect that was already there** in a region the change's layout affects goes to the user before the push as a finding of the validation round, with fix now or a ticket recommended as the ticket rule of [scope changes](../plan/scope-changes.md) sets; fix in this round the ones the user picks. When the delivery does not stop for validation it goes to the close's findings, as [close report](../close/close-report.md#findings) sets, and the final report lists each difference from the approved example that remains.
- **States the UX reviewer did not cover:** cover each in your own walk, or report it as not verified, in the validation round or, when the delivery does not stop for validation, in the final report.
- **A second review** follows a fix that changed logic or a contract, limited to the fixes' diff and the callers of what changed. A blocking finding of that review gets a local fix with its test and an `Unreviewed: <reason>` line in its commit message, or goes to the user when the fix is not local. Non-blocking findings go to the close's findings, not to another round, since the round of fixes runs once; the report says the second review does not cover what the first one missed.
