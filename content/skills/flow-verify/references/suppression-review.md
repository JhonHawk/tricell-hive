# Review of weakened checks

Read for every candidate, whatever review mechanism is selected. The verifier supplies this requirement and reference in the review brief, including through the host's native review instruction mechanism when native review is selected. Do not silently replace the selected review if its instructions or coverage cannot be supplied or verified; report this review as unverified.

Inspect the candidate diff for added or widened suppression directives, skipped tests, and configuration exclusions that weaken checks. Inventory each candidate with its location and affected check, or explicitly report that the diff contains none. For each candidate, assess the scope and requirements it affects and record a justified disposition with evidence. A green check alone does not establish that a suppressed failure is fixed.

Report a defect when evidence identifies a concrete failure scenario or broken contract caused or left exposed by the change. A textual match, suppression directive, or explanatory comment alone is not a defect; a justified exception consistent with the requirements can be accepted. Preserve the cause comment for an authorized workaround under [defect fix](../../flow-build/references/defect-fix.md). Return the inventory and dispositions with the review evidence; if any candidate's coverage or disposition cannot be verified, state what remains unverified.
