# UI verification decision

## When to read

Read when the work has a rendered UI effect, to resolve its `UI verification` value in the delivery round that [delivery decisions](delivery-decisions.md) sets, or to look up what each value runs. Before presenting the question, read [questions](questions.md). Reading this reference does not invoke the planning workflow.


Resolve the `UI verification` value in the same exchange when the work has a rendered UI effect other than a text or style change that alters no layout, state, or flow. An explicit answer given earlier in the session for the same repository is reused under the shared workflow-choice rule; name it in the one-line statement that [delivery decisions](delivery-decisions.md) sets. Without one, ask once, in the session language, with the three values as options, each with its effect and its time cost: `full` runs `hive-review-ux` and `hive-verify-change` on the built candidate before completion; `functional` runs only `hive-verify-change` on the acceptance journeys and leaves visual judgment to the human validation, or, under `automatic`, to no one; `none` runs neither and keeps the implementer's bounded checks, which are the last checks before the human validation under `interactive` or `hold` and the only ones before merge under `automatic`, so the user chooses it there knowingly, and records the walkthrough passes with a `hive-verify-change` child that returns no verdict. These definitions are the values' only home; [project settings](project-settings.md) lists `UI verification` as a retired key. Recommend `full` when the change adds or rearranges a screen, dialog, or shared pattern, and `functional` when it changes behavior inside an accepted pattern. Say in each option that the answer holds for the rest of the session in that repository, including later tickets with another surface, and that the user can change it in any request. [The UI gate](../../flow-verify/references/ui-gate.md) applies the value to the gate on the built candidate and to the accepted-candidate gate.
