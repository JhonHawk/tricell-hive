# Explicit unattended delegation

Activate this mode only from an explicit delegation or a declared scheduled job whose scope and expiry match the current work. Silence, a long task, an absent user, or a background turn does not activate it.

At activation, state the objective, root or repository, authorized effects, relevant references, destination, evidence, and an expiry or deadline. Keep normal authorization boundaries and host permissions unchanged; this skill grants neither broader tools nor delivery authority.

Delegate only bounded, independent work when delegation is useful. Give each child a concrete brief and avoid overlapping writers. Continue useful independent work while children run; otherwise wait. Keep consequential decisions and evidence in the existing task record when one exists. Do not require a ledger, branch, hook, or new tracking system solely for this mode.

At expiry or when the objective is complete, stop unattended effects, report completed and unresolved work, and return control to the user. Do not imply activation or success when no matching explicit delegation exists.
