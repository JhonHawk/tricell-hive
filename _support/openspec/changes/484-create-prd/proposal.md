## Objective

Hoy Hive no tiene procedimiento para escribir ni validar un requerimiento: un documento puede declararse «listo para desarrollo» sin que nadie lo contraste, y desarrollo termina decidiendo reglas de negocio. Con el cambio, una skill corta redacta o recibe el requerimiento, lo deja en una estructura fija donde cada regla lleva su estado y su veredicto contra el código, y solo la validación —no el autor— mueve el estado del documento.
