# Harness audit rules: provenance catalog

This catalog records why each rule in the `harness-audit` skill exists. The deployed skill carries only rule IDs and rule text; sources, evidence strength, and verification dates live here and are not distributed. Update this file whenever a rule is added, changed, or retired, and re-verify version-sensitive rules when the installed host version changes.

## Conventions

- IDs use `HA-<area>-<nn>`: `IF` instruction-file content, `HI` instruction hierarchy, `SK` skills, `AG` agents, `ME` measurement and tooling, `PL` project layout.
- IDs are stable. A retired rule keeps its row with status `retired`; its ID is never reused.
- The first column is the ID and the last column is the status, written without backticks, so the parity test `tests/skills/harness_audit_rules_test.py` can compare active IDs with the IDs used by the skill and the `review-harness` role.
- Evidence types: `DOC` official documentation; `OBS` observed locally on the named version; `MEAS` measured study; `CASE` production account without controlled data; `OPIN` practitioner opinion; `DEC` user decision; `LEGACY` carried over from the previous Hive implementation (`agents-md-primary`, master `16e7d33`).
- Primary research record: harness-auditor research (historical evidence omitted from public history).

## Notes not adopted as rules

- **Unreviewed model-generated guidance.** arXiv 2602.11988 and SkillsBench show weaker results for generated context files and skills, but authorship is not detectable from the files, and OpenAI generated its own `AGENTS.md` with Codex. Kept as background for measurement, not as an audit rule.
- **Separate success and cost when measuring guidance.** arXiv 2602.11988 and 2601.20404 are compatible only when both are reported separately. This is a measurement practice, not a file property; see the harness-engineering README measurement standard.
- **Long-session drift.** arXiv 2605.10039 found compliance odds fall about 5.6% per generated function (post hoc). Session length is not a file property, so an audit cannot enforce it.
