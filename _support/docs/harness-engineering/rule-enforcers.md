# Rule enforcers

Which of Hive's rules a mechanism enforces, and which still rest on prose. A rule moves from prose to a mechanism when root `AGENTS.md` «Measurement» marks its watch item `Enforceable:` with that mechanism; this table lists the result. It does not restate any rule: each row links its canonical home.

- **Kind:** `prevents` when the mechanism stops the wrong action or rejects its output before it lands; `detects` when it reports the failure after a session ran, through `go run ./tests/pilot --audit-session`.
- **Status:** `enforced` when the mechanism exists; `judgment` when no mechanism can decide the rule and prose stays its only enforcement.
- `tests/content/rule_enforcers_test.go` fails when a path in the Mechanism column does not exist. Started 2026-11-17 (change `determinism-candidates`).

## Session-end phrases of the session audit

`merged_branch_deleted` in `go run ./tests/pilot --audit-session` takes a user message as the end of the session when it starts with one of these phrases, has at most 10 words, holds no question mark, and continues after the phrase only with punctuation and closing words: «es todo», «eso es todo», «terminamos», «por hoy», «por hoy es todo», «por ahora es todo», «por el momento es todo», "that's all", "that's it for now", followed at most by thanks or farewell words such as «gracias», «por tu ayuda», «nos vemos mañana», "for today", "bye". A message that goes on with other words, such as «es todo correcto, sigue con el siguiente ticket», does not end the session. The lists are a detecting subset kept in `sessionEndPhrases` and `sessionEndClosers` of `tests/pilot/session_audit.go`; [close modes](../../content/skills/hive-core/close/close-modes.md) defines what ends a session, and a phrase outside the lists is a session end the audit does not see.
